Design Thinking Stages (Fresh Discovery Track)

01

Empathize

Observed Friction: Students waste 20-35 mins finding quiet slots or subject mentors between lecture breaks.

Interviews: Conducted with 3 batchmates regarding campus resource visibility.

02

Define

Problem Statement: "Campus undergraduate students need an intuitive, transparent dashboard to check study zone capacity and seek immediate peer mentorship without formal scheduling bottlenecks."

03

Ideate with AI

Generated 12 feature concepts using LLMs, filtered down to 2 high-impact frictionless flows (Live Spaces & Peer Board).

04

Prototype & Test

Developed lightweight web interactive interface tested with 3 real student peers.

Full AI Interaction Audit (Required for RAALE Sem-3)

Documentation of prompts used during the Ideate phase, what was accepted, rejected, and hallucination corrections.

Prompt Given AI Suggestion Status Reason / Hallucination Fix
"Propose 5 campus digital tools to reduce daily college stress." Suggested automatic biometric classroom reservation system. Rejected Requires expensive hardware colleges don't deploy openly; hallucinates easy student API access.
"Create a lightweight peer learning queue with no database dependencies." Recommended client-side session state & instant browser-based board. Adopted Practical, fast, low-friction, easily hostable on GitHub Pages.
"How to validate study desk density accurately?" AI suggested camera live-feed processing with OpenCV in frontend. Corrected Hallucinated browser security permissions; replaced with crowdsourced check-in status.
